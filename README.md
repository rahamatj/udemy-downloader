# Udemy Downloader

This is a simple udemy downloader forked from ```https://github.com/ShiroNexo/udemydl```
You can download the courses you won.



## Installation
- ```git clone https://github.com/rahamatj/udemy-downloader```
- ```cd udemy-downloader/src```
- ```node index.js```
- See the original [repo](https://github.com/ShiroNexo/udemydl) to know how to setup cookies
